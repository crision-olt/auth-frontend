# Auth Frontend

React frontend for the Auth SSO Service.

## Setup

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```

Frontend will run on http://localhost:3000

## Pages

- **Login Page** (`/`) - Register or login form
- **Dashboard** (`/dashboard`) - User profile and links to demo apps
